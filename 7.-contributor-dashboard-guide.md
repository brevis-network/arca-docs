# 7. Contributor Dashboard Guide

The Contributor Dashboard is where Contributors sign-in, connect a GitHub account, browse available Call-for-Data opportunities, track submissions, and view earnings and payout history.

To access the dashboard, please visit: [https://dashboard.arca.market/](https://dashboard.arca.market/).

{% stepper %}
{% step %}
### Sign in or sign up

Visit the [Contributor Dashboard](https://dashboard.arca.market/) and sign-in/sign-up with an email or Google account.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 14.41.42.png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Accept terms and privacy policy

New users must accept Terms of Service and Privacy Policy before sign-up is complete.

Note: Arca is currently **invite-only**. Enter your invite code on the sign-up screen.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 14.45.40.png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Connect GitHub

Connect GitHub to unlock submission review and reputation-based reward signals. Once connected, your GitHub [reputation score](4.-core-concepts.md#contributor-reputation-score) will appear in the top-right corner.

{% endstep %}

### Check the tutorial

The tutorial walks through the Dashboard: install app, browser open calls, upload sessions, and connect a wallet to get paid. You may skip this step.

### Get started

To get started, install the Arca app, browser available Call-for-Data opportunities, and connect a wallet.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 14.57.01.png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Install Arca App and submit sessions

To submit AI sessions, first install the Arca App. Please refer to [this guide](6.-arca-app-guide.md) to learn how the Arca App works.
{% endstep %}

{% step %}
### Track submissions

Check My Submissions to track each submission through In review, Approved or Rejected. Each row shows a session ID, an artifact hash and a download of exactly what was uploaded, so you can check what was reviewed against what you sent.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 15.06.49 (2).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Manage profile

You can manage your account information, avatar, display name, connected accounts and connected wallet in Profile page.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 15.09.19 (1).png" alt="" width="563"><figcaption></figcaption></figure>
{% endstep %}

### Check earnings and connect payout wallet

The Earnings & Payouts page shows total earnings, payouts, available balance, and payment methods.

<figure><img src=".gitbook/assets/Screenshot 2026-09-11 at 15.13.53.png" alt="" width="563"><figcaption></figcaption></figure>

If no payout wallet is connected, click "CONNECT WEB3 WALLET" and choose a supported wallet provider and sign the message to connect.
