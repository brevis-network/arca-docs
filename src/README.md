# 1. Overview

<div align="center"><figure><img src="assets/doc (1).png" alt=""><figcaption></figcaption></figure></div>

Arca is an open, verifiable AI data platform, allowing contributors to submit private AI workflow data to earn rewards.

Arca starts with the sessions people already have: work done with AI models in coding tools and desktop chat, optionally paired with the code repo or workspace the session worked in.

A session may include prompts, responses, tool usage, code changes, debugging steps and, if attached, repo or workspace context. Arca anonymizes it on your machine before upload and submits it for reward evaluation.
